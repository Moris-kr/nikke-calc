니케 계산기 MCP · ChatGPT와 Claude 연결

NIKKE Calculator MCP를 ChatGPT·Claude 등 AI 도구에 연결하는 방법. 브라우저에서 육성과 전투 조건을 사용해 덱 비교·계산을 요청하고 연결 안내를 확인하세요.

관련 기능 열기

AI와 계산기를 연결하면

MCP 연결은 AI가 계산기의 기능을 도구로 요청할 수 있게 해 줍니다. 덱 구성 후보를 검토하거나 동일한 조건의 계산을 비교하는 데 사용할 수 있습니다. 실제 사용 가능한 도구와 연결 방법은 편의 기능 → MCP 탭의 안내를 확인하세요.

계산은 어디에서 실행되나요?

이 계산기의 AI 연동은 사용자의 계산기 브라우저를 통해 연산하도록 구성되어 있습니다. 계산기 페이지를 열고 연결 상태를 확인한 뒤 사용하세요. 사용 중인 브라우저의 육성 설정과 현재 전투 조건을 먼저 맞추는 것이 좋습니다.

연결 확인용으로 이렇게 요청하세요

“NIKKE Calculator 연결 상태를 확인하고, 현재 사용할 수 있는 계산 기능과 내 브라우저에 설정된 전투 조건을 알려줘. 확인하지 못한 값은 추측하지 마.”라고 요청해 보세요. 답변에서 실제 도구 호출과 확인한 조건을 살펴보면 연결 여부를 점검하기 쉽습니다.

계산을 요청할 때 적으면 좋은 것

보스 이름·속성·전투 시간과 고정할 니케, 제외할 니케를 함께 적습니다. 여러 덱을 비교한다면 같은 육성과 전투 조건을 유지하도록 요청하세요. ChatGPT와 Claude의 연결 메뉴나 지원 범위는 서비스·요금제에 따라 달라질 수 있으므로 사이트의 연결 안내와 해당 서비스의 설정 화면을 함께 확인하세요.

# 임시 캐릭터 이미지

- `sin-swift-bunny-card.png`: 신 : 스위프트 바니, 사용자가 제공한 원본 카드.
- `guilty-mighty-bunny-card.png`: 길티 : 마이티 바니, 사용자가 제공한 원본 카드.

2026-09-16 사용자 승인에 따라 원본 파일을 수정 없이 사용한다. 누끼, 가려진 부분 복원,
AI 생성 또는 의상 변경을 하지 않았다. 이미지 저작권은 원권리자에게 있다.

캐릭터의 임시 계산 데이터 정본은 `site/src/temporary-characters.json`이다.
기업·무기·등급·코드·3버스트·화력형 클래스는 사용자 제공 정보다.
무기 수치, 버스트 쿨타임, 스킬 및 계수는 창작이며 실제 성능을 나타내지 않는다.

# 재설계 시안 브리프 (공통)

NIKKE 스쿼드 계산기의 UI/UX를 **처음부터 다시 짠다**. 기존 배치를 손보는 게 아니라
정보 구조와 시각 언어를 통째로 새로 세우고, **기능만 그대로 가져온다**.

시안 단계에서는 계산 엔진을 붙이지 않는다 — 가짜 수치로 채운 **동작하는 화면**이면 된다
(탭 전환, 창 열고 닫기, 토글, 접이 정도는 실제로 움직여야 한다).

## 반드시 따를 것

`.agent/skills/supanova-taste/SKILL.md`와 `.agent/skills/supanova-soft/SKILL.md`를 읽고 그
규칙을 따른다. 요약하면:

- **단일 HTML 파일**. Tailwind CDN + 인라인 스타일/스크립트. 빌드 도구 없음.
- **Pretendard** 필수(한국어), 영문 디스플레이 폰트는 Outfit/Geist 등에서 하나.
  `Inter`·`Noto Sans KR`·`Roboto`·`Arial` 금지.
- 아이콘은 **Iconify Solar 세트만**. `<iconify-icon icon="solar:...">`. **이모지 금지**.
- 액센트 색 **한 가지**. 보라/파랑 "AI" 그러데이션 금지. 다크 기본.
- 한국어 타이포: `break-keep-all`, 제목은 `leading-snug`(`leading-none` 금지).
- 모션은 `cubic-bezier(0.16, 1, 0.3, 1)`. `linear`·`ease-in-out` 금지.
  `transform`·`opacity`만 애니메이션한다.
- `h-screen` 금지 → `min-h-[100dvh]`. 좁은 화면에서 한 열로 접힌다.
- 카드는 더블 베젤(바깥 셸 + 안쪽 코어 + 내부 하이라이트)을 기본으로.

## 담아야 할 기능 (하나도 빠뜨리지 말 것)

### 편성
- 5덱 모드(덱 1~5 전환), 덱 비우기, 현재 덱 복사, 덱 순서 이동
- 슬롯 5칸: 초상화, 슬롯 번호, 속성(코드) 표시, 좌우 자리 이동, **돌파·코어강화 스테퍼**
  (별 3개 + 진화 숫자), 이름/버스트단계/코드/무기, 칸 비우기
- 슬롯마다 **개별 설정 on/off**, 개별값 요약(«3돌 · 호감도 30 · 스킬 10/10/10 · 우코 …»)
- 캐릭터 설정: 돌파·스킬 레벨(1/2/버스트)·오버로드 9종·큐브(**«없음» 포함**)·소장품/애장품·
  장비(미장착 / T9(일반) / T9 기업 / 오버로드 1~5강)·수동 스탯
- 컨트롤: 추천 자동 / 직접 설정, 재장전 컨트롤·버스트 엄폐 컨트롤·톡톡이·홀드,
  **버스트 운용**(자동 / n의 배수 우선 / 막바지 최우선(n초) / 안 씀)
- 니케 고르기: 검색(초성·별칭), 정렬(전투력·이름·우월코드·우공합), 버스트 필터 B1·B2·B3·BA,
  등급/클래스/코드/무기/기업 필터, 로스터 그리드
- 도구: 렛츠도로 CSV 불러오기, 블라블라링크 연동, 새 니케 추가, 편성 프리셋, 조합 공유,
  완전 초기화, **설정 이어받기 토글**

### 전투 조건
- 전투 시간 · 적 코드 · 싱크로 레벨 · 코어 있음/직경 · 파괴 가능 파츠 · 적정거리(무기군)
- 고급: 적 방어력 · 난수 시드 · 버스트 게이지 충전 · **덱마다 따로** · 버스트 반응속도 ·
  난수 처리 · 족자 중 충전 정지 · 평타 계수(6무기군) · 보스 페이즈(족자/속저 구간)
- 콘솔(공통 / 기업 5 / 클래스 3)
- 전투 조건 공유 · 적 수치 초기화 · 저장된 결과 지우기

### 실행 · 결과
- 시뮬레이션 실행(가장 자주 누르는 단추), 진행 상태, 오류 표시
- 결과: 총 대미지 · DPS · 덱 5개 비교(순위 1·2위 강조, **순서는 덱 번호 그대로**)
- 캐릭터별 기여(초상화 · 기여% · 막대 · 총딜), 평타/스킬 분해, 스킬별 내역
- 전투 사실(초·히트·시드), 기본 스펙 이탈 목록
- 결과 저장 / 결과 불러오기 / 보고서 이미지 만들기

### 타임라인
- 덱 탭, 초당 대미지 선 그래프, 버스트를 **초상화 핀**으로, 족자·속저 구간 밴드

### 공유 (전투 조건 · 조합 각각)
- 탭 셋: 올리기 / 내려받기 / 코드
- 올리기: 이름(필수) · 설명(자동 생성, 읽기 전용) · 업로더(비우면 익명)
- 내려받기: 검색, 목록(이름·설명 또는 조합 초상화·업로더·시각·👍/👎·적용 횟수·적용 단추)
- 코드: 내 코드 / 공유 링크 / 받은 코드 적용 / 이 브라우저에 저장(프리셋)

### 그 밖
- 업데이트 공지 창(처음 들어오면 한 번, 닫으면 다시 안 뜸)
- ENIKK 조합 가져오기 화면
- 계산 기록, 완전 초기화 확인, 블라블라링크 연동, 렛츠도로 안내 창

## 출력 규칙

- 파일 하나: `site/redesign/concept-<번호>.html`
- 페이지 맨 위에 **한 줄 소개**(이 시안이 무엇을 노렸는지)를 눈에 띄게 둔다.
- 실제로 눌러지는 것: 화면/탭 전환, 창 열고 닫기, 접이, 토글, 덱 전환, 정렬·필터 칩.
- 수치는 가짜여도 되지만 **자릿수와 단위는 실제와 같게**(총딜 1,482,905,113 / 8.24M DPS 등).
- 플레이스홀더·«여기에 …» 같은 미완성 표시 금지. 모든 화면이 채워져 있어야 한다.

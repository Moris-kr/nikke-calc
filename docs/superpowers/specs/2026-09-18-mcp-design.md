# 계산기 MCP 설계

사용자가 승인한 범위: 기존 엔진을 사용하는 캐릭터 조회·단일 계산·조건 비교 MCP,
로컬 실행 세팅, 원격 Docker 배포 구성, 한국어 ChatGPT/Claude 연결 튜토리얼.
현재 원격 서버는 없으므로 공용 서버 배포나 계정 연결 완료를 주장하지 않는다.

- Python 3.10 이상, 공식 MCP Python SDK 2.2.0. stdio와 Streamable HTTP 지원.
- 기존 `site/pybridge/bridge.py:run_request`를 새 프로세스에서 호출한다.
  계산식 복제, 사용자 파일 읽기, 임의 코드 실행, 커스텀 캐릭터 주입은 제공하지 않는다.
- 기본값과 입력을 결과에 함께 반환한다. 결과는 엔진 버전 해시로 재현 가능하다.
  기본 기대값 모드, 고정 seed. 요청은 1~5명/1~180초, 비교는 2~5개 후보.
- 별도 프로세스, 실행 시간 제한, 동시 계산 제한, HTTP 본문 제한을 둔다.
  결과를 서버에 저장하지 않는다. 계산 결과 상세는 동일 요청을 detail=true로 재실행한다.
- HTTP 기본 바인딩은 127.0.0.1. 원격은 명시적 공개 실행 옵션과 Host 허용 목록 필요.
  최초 버전은 인증 없는 공개 계산 도구다. 로그인/프로필 보관은 제공하지 않는다.
- MCP 클라이언트와 HTTP/stdio 통합 테스트, 웹 브리지와 결과 일치 테스트를 실행한다.
- 튜토리얼은 가상 예제만 사용한다. 개인 대화/프로필/토큰을 캡처하지 않는다.

연결과 도구 호출은 로컬 SDK 클라이언트로 검증한다. 실제 ChatGPT/Claude 연결에는
접근 가능한 HTTPS 서버와 각 제품의 연결 권한이 필요하다는 점을 구분한다.

# Calculator MCP Implementation Plan

**Goal:** 기존 엔진을 재사용하는 MCP와 한국어 설치 가이드를 제공한다.
**Architecture:** 검증 모델 → 제한된 실행기 → 요청별 Python 프로세스 → 웹 브리지.
**Tech Stack:** Python 3.10+, mcp 2.2.0, Pydantic, unittest, Docker.
**Spec:** `docs/superpowers/specs/2026-09-18-mcp-design.md`

## 작업 순서

1. `nikke_mcp/test_service.py`: 없는 이름·중복·범위 밖·미지원 키 거부,
   큐브 없음, 웹 브리지 동등성, 비교 조건 일치, 프로세스 시간 제한 테스트 작성.
   `python -m unittest nikke_mcp.test_service`로 실패 확인.
2. `nikke_mcp/models.py`, `service.py`, `worker.py`: 요청 검증과
   프로세스 격리 실행 구현. 같은 테스트 통과 확인.
3. `nikke_mcp/server.py`, `__main__.py`: 조회/계산/비교 도구 및 stdio/HTTP 구현.
   `test_protocol.py`로 실제 클라이언트 목록 조회·계산·HTTP Host 거부 검증.
4. `nikke_mcp/requirements.txt`, `Dockerfile`, 설치 스크립트와 샘플 설정 추가.
   깨끗한 가상환경 설치, 임의 작업 디렉터리에서 stdio 연결 확인.
5. `docs/MCP_SETUP.md`: 로컬·Docker·ChatGPT·Claude·오류 해결·예제 작성.
   사이트에서 찾을 수 있는 안내 링크 추가. 개인정보 없는 예제로 안내한다.
6. 새 테스트, 브리지 테스트, 문서 검사, 사이트 빌드와 변경사항 검토.
   커밋·푸시 후 GitHub 배포 성공 및 사이트 반영 확인.

서버 없는 환경이므로 Docker 산출물과 로컬 실행을 완료하되,
공개 원격 서비스 및 실제 제품 계정 연결은 완료 범위와 구분한다.

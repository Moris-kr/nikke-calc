# 샷건 히트맵

계산기에서 전투를 계산한 뒤 샷건이 포함된 덱의 **샷건 히트맵 보기**를 누른다. 보스메이커에도 계산이 끝나면 같은 버튼이 표시된다. 창을 처음 열 때만 결과에 저장된 요청으로 진단을 다시 계산한다. 화면에서 아직 계산하지 않은 변경값은 사용하지 않는다.

- 캐릭터 버튼: 샷건 사격을 기록한 캐릭터를 선택한다.
- 시점별 탄착군: 시간 막대, 그래프 클릭, 이전/다음 사격으로 당시 조준점과 판정을 확인한다.
- 재생: 사격 시각에 따라 탄착군이 변하는 모습을 본다. 0.5/1/2/5배 속도를 지원한다. 점이 이동하는 모션은 설명용이며 실제 게임 투사체 속도가 아니다.
- 전체 탄착 밀도 / 명중 구분: 모든 사격을 펠릿 수로 가중 합산한 기대 분포를 본다. 윤곽은 선택 시점 기준이다.
- 우측 상세: 전체 펠릿 기준 명중·몸통·코어·빗나감 비율, 발사 펠릿과 사격 횟수, 사격별 명중 보정과 탄착 직경, 풀버스트 여부별 명중률을 확인한다.

엔진과 동일한 1,024점 적분으로 48×48 격자에 기대 펠릿을 누적한다. 화면상의 1,024점은 한 발의 실제 펠릿 수가 아니다. 화면 재생은 기록된 상태를 읽기만 하며 전투를 매 프레임 재계산하지 않는다. 진단 수집은 전투 난수를 소비하지 않으며 대미지를 변경하지 않는다. 난수 모드에서도 히트맵은 실제 추첨 탄흔이 아닌 조건부 기대 분포다.

기존 고정 확률 방식은 명중 실패의 공간 위치를 정의하지 않으므로 밀도만 보여주고 공간별 명중 구분은 비활성화한다. 도형 모드는 계산 당시 실제 도형·활성 구간·조준점·코어 노출을 기록한다. 무적/속성 저항의 최종 피해 처리, 관통 중첩, 스킬 추가 대미지는 공간 히트맵에 포함하지 않는다. 탄착 분포·보스 크기는 기존 모형 가정이며 실게임의 완벽한 재현을 보장하지 않는다.

진단 데이터는 열린 페이지 메모리에 재사용한다. 창을 닫으면 재생이 정지하고, 같은 결과에서 다시 열면 완료된 진단을 재사용한다. 새로고침하면 다시 계산한다. 이 변경은 기존 전투 계산 방식이나 회귀 기준값을 바꾸지 않는다.

# 픽업 연표 데이터 갱신

원본은 이 폴더의 `pickup-history-2022-2025.json`과 `pickup-history-2026.json`이다. 날짜는 KST 달력 날짜이며, 종료일 전체에 모집 가능하다는 뜻이 아니다. 시각을 확인하지 않은 기록에 임의의 점검 종료 시각을 붙이지 않는다.

공개 BannerHistory 일정 아카이브에서 출발해 공식 공지와 공지 재게시 자료로 주요 오류를 교정했다. 모든 과거 공지를 독립적으로 검수한 데이터는 아니다. 특히 이벤트 개최 기간과 모집 기간, 일반 모집 편입과 기간 한정 모집, 동시 독립 모집과 선택 복각을 구분한다. 2023년 겨울처럼 신규 모집 확률표 안에 포함된 복각은 상세 note에 적는다.

최근 공식 대조: 2026-06-11 여름 6인 선택 복각, 07-23 라플라스/맥스웰 일반 모집 편입, 09-17 길티/신 일반 모집 편입 및 겨울 6인 선택 복각. 09-24 신 : 스위프트 바니는 자료 확인일 현재 예정이다. 원문 링크는 각 JSON의 sources와 sourceIds에 기록한다.

갱신할 때는 정식 캐릭터 이름과 공지의 시작·종료 날짜, 신규/복각, 한정/콜라보 여부를 확인하고 출처를 추가한다. 확인되지 않은 미래 일정은 만들지 않는다. `site/scripts/build-pickup-history.mjs`의 updatedAt도 실제 확인 날짜로 갱신한 뒤 site 디렉터리에서 `npm run build-pickup-history`를 실행한다. 공개 산출물은 `site/public/pickup-history.json`이다. UI는 이를 읽으며 계정 육성이나 프로필을 사용하지 않는다.

`npm test -- --run src/pickup-history.test.ts src/pickup-history-data.test.ts`로 스키마, 출처 참조, 실제 캐릭터/이미지 대응, 데이터 재생성 일치, 검색과 예정 표시를 검증한다. 전체 프런트엔드 테스트와 빌드 후 배포한다.

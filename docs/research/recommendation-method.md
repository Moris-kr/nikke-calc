# 덱 추천 기준 — 2026-09-18

## 조사와 해석

ENIKK Meta는 에디터 평점이 아니라 사용량이다. Hard Campaign 전체 구간 상위 9개 조합과, 수집된 최신 약점별 Solo Raid S40~S36 상위 5개씩 총 25개 조합을 직접 확인했다. 최신 S41·S42에는 자료가 없었다. 시즌별 절대 피해량·평균 전투력은 육성이나 보스 조건이 다르므로 서로 성능 점수로 합치지 않는다. 원본 숫자와 출처는 동반 JSON에 보존했다.

하드 캠페인 상위 9개 모두 아니스 : 스타·크라운을 포함했다. 이것은 후보 구성의 강한 관측 근거지만 두 캐릭터의 인과적 기여나 필수 보유를 증명하지 않는다. 챕터·스테이지별 재검색으로 전체 통계의 편향을 줄인다. Normal 요청도 추천하되 Normal 자료가 없으므로 Hard 기록을 참고했다고 반드시 설명한다. Compositions는 슬롯 순서를 합쳐 집계하므로 표시 순서를 검증된 버스트 순서로 쓰지 않는다.

## 왜 함께 쓰는가

다음 설명은 사용 횟수와 별도로 스킬 정본에서 확인한 메커니즘 해석이다. 실제 수치는 get_character에서 사용자 스킬 레벨로 조회한다.

- 아니스 : 스타는 자신 외 기본 B1이 없을 때 팀 쿨감을 제공한다. B1 진입과 쿨감, 풀버스트 시작 시 공격력·순차 공격 지원을 함께 제공해 반복 버스트 딜러와 맞물린다. 크라운은 버스트 사용 아군의 공격력·재장전, 회복 시 공격 대미지, 보호막을 지원한다. 회복 트리거는 실제 회복 공급/자체 회복 타이밍을 확인해야 하며 무조건 상시로 계산하지 않는다.
- 스노우 화이트 : 헤비암즈는 록온 광역·순차 공격과 관통/파츠 공격을 갖는다. 아니스의 순차 공격 지원과 원문상 연결되지만, 실제 웨이브/타깃 수·록온·차지 운용에 따라 가치가 바뀐다. 네온 : 비전 아이도 풀차지·화력 게이지·풀버스트 종료의 조건을 갖는다. 캠페인 웨이브 제어를 단일 보스 피해량으로 환산하지 않는다.
- 마스트 : 로망틱 메이드는 취기 중첩의 분배 대미지·재장전 지원과 숙취 기절을 함께 가진다. 앵커 : 이노센트 메이드의 분배 대미지/해로운 중첩 감소와 홍련 : 흑영의 분배 공격이 맞물리는 계열이다. 중첩과 풀버스트 순서를 확인한다. 크라운과 마스트를 같이 넣을 때 B2 사용 우선순위를 따로 검증한다.
- 토브·도로시 : 세렌디피티·아르카나 : 포츈 메이트·드레이크·솔린 : 프로스트 티켓은 S40 1969회, S37 1281회 관측됐다. 토브의 샷건 공속·공격력, 바니 아르카나의 샷건 공격 대미지, 바니 도로시의 펠릿 명중/관통, 솔린의 팀 쿨감이 연결된다. 드레이크 애장품 등 실제 육성 조건을 보존한다. 소다 : 트윙클링 바니로 솔린을 대체하는 풀버스트 연장 샷건덱만 쿨감 예외를 인정한다.
- 리틀 머메이드의 풀버스트 종료 쿨감, 리타의 풀버스트 횟수별 쿨감은 다양한 딜러 계열의 사이클을 지원한다. 레드 후드 등의 자기 쿨감은 이를 대신하지 못한다. 목단은 애장품 단계에 따라 유효 팀 쿨감이 달라지므로 이름만 보고 통과시키지 않는다.
- 그레이브·앨리스 계열은 관통 버프와 체력 조건부 관통 특화가 연결된다. 민트·프리카 계열은 보컬·퍼포먼스와 관통/발사체 폭발 지원이 연결된다. 브리드 : 사일런트 트랙의 풍압 적 대상 받는 대미지 증가는 S40 풍압 보스에는 맞지만 다른 보스에 일반화할 수 없다.
- 이사벨의 풀버스트 단축과 아르카나의 종료 조건 계열은 긴 풀버스트가 항상 이득이라는 가정을 깨는 사례다. 아르카나의 운명의 수레바퀴 등 확인되지 않은 발동 조건은 조건부로 표시한다.

## 실행 가능한 알고리즘

1. 실제 브라우저 roster와 battle을 확인한다. 목표 보스·약점·스테이지, 필수/제외, 덱 수를 확정한다. 자료 누락을 미보유로 단정하지 않는다.
2. 같은 콘텐츠의 ENIKK 완성 조합을 씨앗으로 삼는다. 보유하지 않은 자리는 무기/대미지 종류/버스트 단계/쿨감 역할을 보존한 대체 후보를 별도로 만든다. 원본 관측 조합과 대체 가설을 표시한다. 상위 사용 캐릭터 5명을 단순히 합치지 않는다.
3. 각 후보의 유효 팀 쿨감, 실제 애장품/스킬/운용, 버스트 진입·탈출, 중복, 필수/제외를 검사한다. 사용자 지정 무쿨감 덱은 의도를 한 번 확인한다. 새 추천에는 동의 우회가 없다. 후보의 쿨감이 조건부뿐이면 자동 추천에서 제외하고 발동 조건을 먼저 검증한다.
4. 후보 최대 20개를 사용자 컴퓨터에서 같은 육성·조건·expected RNG로 계산한다. 기본 조건 외에 불확실한 코어/방어력/파츠/노출 구간/버스트 충전 시간 등 최대 2개 조건을 비교할 수 있다. 실제 관측 또는 명시한 가정만 입력한다. 실패한 후보는 제외 이유를 기록하며 0점으로 위장하지 않는다.
5. 중복 없는 N덱 선택을 입력 후보의 모든 가능한 조합에서 정확히 탐색한다. 각 조건 s의 최고 가능한 총 피해량을 B_s, 선택 묶음 G의 총 피해량을 D(G,s)라 하면 R(G)=max_s(1-D(G,s)/B_s)를 최소화한다. B_s=0이면 해당 손실은 0, 동률이면 기본 조건 총 피해량을 우선한다. 조건이 하나면 총 피해량 최대화와 같다. 1덱부터 순서대로 고르는 탐욕법과 달리 공용 서포터 선점에 따른 손실을 함께 고려한다.
6. 추천과 대안, 계산된 총 피해량, 조건별 순위 변화/상대 손실, 쿨감 담당, 적용 육성, 출처/날짜, 미검증 기믹을 함께 보고한다. 상대 손실은 선택한 조건 내 민감도 지표이며 성공 확률이나 통계적 신뢰도가 아니다.

## 검증 범위와 한계

선택은 입력 후보 안에서만 최적이다. 20개를 넘는 풀을 나눠 계산한 뒤 각 배치 우승자만 모으면 전역 최적화가 아니므로 그렇게 주장하지 않는다. 커스텀 버스트 순서/덱별 육성 변경은 별도 simulate_squad/compare_setups로 검증한다. 후보의 슬롯 순서와 현재 캐릭터 운용이 보존되지만 ENIKK 슬롯이 최적 버스트 순서라고 가정하지 않는다.

엔진의 버스트 게이지 충전은 설정된 시간을 사용하며 실제 사격 기반 게이지·캠페인 웨이브·투력 페널티·생존/저지·컨트롤을 완전 재현하지 않는다. 풀버스트 진단은 완료된 타임라인 구간만 포함한다. 따라서 캠페인은 동일 Hard 구간의 실제 클리어 근거를 우선하고 피해량 순위는 보조 판단으로 표시한다. 솔로레이드도 기믹과 생존 검토를 통과하기 전에는 최종 확정으로 표현하지 않는다.

신경망은 현재 도입하지 않는다. 관측 기록은 육성·조작·보스·패치가 통제된 학습 정답이 아니므로 학습 점수에 신뢰도 %를 붙일 근거가 없다. 현재는 원문 스킬 제약 + 관측 후보 + 결정론적 계산 + 제한된 후보의 정확 탐색으로 근거를 재현한다. 후속 학습 모델은 계정·시즌 분리 평가, 실측 오차 검증, 신뢰도 보정이 확보된 뒤 후보 생성 보조로만 사용한다.

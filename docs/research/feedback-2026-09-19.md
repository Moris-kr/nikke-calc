# 2026-09-19 피드백 검토

## 팬텀 대미지 과대 제보

사용자가 확인한 클로틴은 길로틴 : 윈터 슬레이어이다. 팬텀 자체의 단검·애장품 처리뿐 아니라 함께 편성한 길로틴 : 윈터 슬레이어의 경험치 적용 대상을 추적하여 확정 오류를 발견했다. 본인에게만 적용될 경험치가 팀 전체 몸통 명중 이벤트를 사용해 다른 공격자에게도 적용되고 있었다. 본인의 일반 공격 6회 명중과 그 발의 비코어 조건으로 분리하고, 코어 명중으로 얻는 경험치와 하나의 스택·100중첩 상한을 공유하도록 수정했다. 일반 명중 카운터는 코어 여부와 무관하게 진행한다는 기존 명세를 따른다.

회귀 테스트는 아군 명중의 경험치 유입 차단, 코어·비코어 혼합 누적과 상한, 실제 발사 경로, 파츠 유무에 따른 독립성을 검증한다. 이 수정만으로 실측과의 일치를 보증하지 않는다. 코어 크기에 따른 명중률 민감도가 남아 있으므로 보스 코어 크기·노출 시간 또는 실제 코어 명중률을 맞춘 뒤 잔여 오차를 조사한다. 기존 context/scenarios/팬텀.md의 오래된 시뮬레이션 수치를 현재 실측값으로 취급하지 않는다.

## 구현 범위

유효 사거리 구간은 [시작, 종료)이며 중첩 구간의 무기군을 합친다. 구간 밖은 기존 상시 설정을 사용한다. 빈 무기군을 지정한 구간에는 보너스가 없다. UI, 요청 검증, 캐시, 공유 코드, Python 브리지, MCP, 타임라인에 연결한다.

보스 메이커는 코어 노출 구간 편집 및 복수 덱 계산과 결과 전환을 제공한다. 코어 크기·파츠 등 도형 기반 조건은 기존처럼 보스 메이커 도형을 기준으로 계산한다.

# 2026-09-19 피드백 검토

## 팬텀 대미지 과대 제보

사용자가 확인한 클로틴은 길로틴 : 윈터 슬레이어이다. 팬텀 원문, 파싱, 애장품 판본 선택, 30명중 단검 공급, 3중첩 소비, 자신의 버스트 후 분배 스택 제거를 점검했다. 기존 사용자 확정 명세와 일치하여 확정 오류로 수정할 항목을 찾지 못했다. 이는 실게임 대미지 일치를 보증하지 않는다.

비교에 필요한 자료: 팬텀 애장품 단계, 같은 전투의 계산기 설정과 팬텀 실측 총딜·버스트 사용 횟수. 설정을 맞춰도 차이가 남으면 30~60초 영상에서 단검 분배 발동 횟수와 피해량, 팬텀 버스트 1회 피해량을 분리해 확인한다. 기존 context/scenarios/팬텀.md의 오래된 시뮬레이션 수치를 현재 실측값으로 취급하지 않는다.

## 구현 범위

유효 사거리 구간은 [시작, 종료)이며 중첩 구간의 무기군을 합친다. 구간 밖은 기존 상시 설정을 사용한다. 빈 무기군을 지정한 구간에는 보너스가 없다. UI, 요청 검증, 캐시, 공유 코드, Python 브리지, MCP, 타임라인에 연결한다.

보스 메이커는 코어 노출 구간 편집 및 복수 덱 계산과 결과 전환을 제공한다. 코어 크기·파츠 등 도형 기반 조건은 기존처럼 보스 메이커 도형을 기준으로 계산한다.

# 샷건 공간 판정 적용 및 롤백

## 적용 범위

- `legacy`: 기존 확률·도형 판정 그대로. 모델 키가 없는 요청/저장/공유 코드는 이 방식이다.
- `spatial-v1`: 보스메이커 도형 또는 중앙 원형 표적과 탄착군을 함께 적분한다. 기본 SG 28명의 공개 탄착 필드를 보존한다. 원본 스케일 250을 기존 모델 직경 240에 대응시킨 상대 단위이며 실제 화면 픽셀 측정값이 아니다.
- `spatial-convergence-v1`: 위 방식에 발사 후 원본 `per_shot`만큼 수렴, 재장전 동안 `recovery`/초로 회복하는 **미검증 시간 가정**을 더한다. 프리바티 : 언카인드 메이드에서 차이가 난다. 기본 선택이 아니며 원시 필드의 공식 해석이라고 주장하지 않는다.

새 브라우저는 spatial-v1이 선택된다. 기존 브라우저 저장과 옛 공유 코드는 legacy를 유지한다. 계산 방식 드롭다운으로 즉시 비교·복귀할 수 있다. 크기 프리셋은 직경 360/200/120의 모델 표적이며 경험적으로 측정한 보스 등급이 아니다. 커스텀은 1~2000. 기존 100/90/80%도 legacy 선택 시 남는다.

모델·직경은 요청 정규화, 결과 캐시 키, 전투 조건 공유(NK3), 보스 공유(NK5), MCP, 일반 계산기와 보스메이커에 함께 전달한다. 샷건 평타 계수는 1을 유지한다. 결과 카드에는 발사 펠릿 전체 기준의 예상 명중·코어·빗나감 비율을 표시한다. 난수 모드에서도 이 진단 표시는 각 사격 시점의 조건부 기대값이다.

## 아직 근사인 부분

- 내부 공간 분포는 기존 power 2.55 가정을 유지한다. 원본 탄착 데이터만으로 펠릿 분포와 카메라 변환이 확정되는 것은 아니다.
- 도형 모드는 사용자가 그린 2D 판정이다. 실물 히트박스/가려진 코어/3D 깊이를 자동 추출하지 않는다. 캐릭터별 수동 탄착 직경을 지정한 경우 그 값이 최종 반경을 덮어쓴다.
- 펠릿 간 독립, 임계치 스킬의 기대 카운터, 고정 관통 중첩 개수는 기존 근사다. 본 변경이 이 부분까지 실측 검증한 것은 아니다.
- 수렴 실험은 명시적 정책을 테스트한 것이며 게임의 시간 규칙을 검증한 것이 아니다. 미사격 대기나 사격 중단에 대한 별도 회복 규칙은 아직 가정하지 않는다.
- 기본 SG가 아닌 무기 변환은 기존 모드별 accuracy_weapon/명중 하한을 따른다. 변환 중 원래 무기의 수렴을 물려받지 않는다.

## 검증

단위 테스트는 공간 교집합과 명중 버프 반응, 몸통·코어 공동 확률, 기존 모드 호환, 수렴 선택/회복/무기 변환 격리, 실제 발사 수 진단을 검사한다. 피드백 스킬을 제거한 통제 사격에서는 기대값과 120개 시드 난수 평균을 비교한다. 이 비교는 수학 구현 검증이며 게임 실측 대조가 아니다.

기존 회귀 29편성은 모델 미지정 legacy로 유지한다. 기준값은 갱신하지 않는다. 신규 모델은 별도 테스트로 검사한다. 모델 버전을 바꾸는 후속 변경은 새 키를 사용해 이미 저장된 spatial-v1의 의미를 바꾸지 않는다.

적용 검증: 엔진 246개(1개 기존 skip), 프런트엔드 전체 880개와 최종 변경 관련 342개, MCP 73개, 회귀 29편성을 확인했다. 프로덕션 빌드와 문서 검증을 통과했다. 실제 브라우저에서도 작은 표적의 공간 판정 결과 표시와 legacy 전환 후 재계산을 확인했다. 이는 소프트웨어 동작 검증이며 실게임 정확도 보증은 아니다.

## 롤백

1. 개별 사용자는 전투 조건 → 샷건 계산 방식 → **기존 방식 · 고정 명중률**을 선택하고 다시 계산한다. 캐시 키가 달라 예전/새 결과가 섞이지 않는다.
2. 코드 롤백 기준은 `cf39e2121acb0f81be00cb98d58bf0fca01b8cc9`다. 이번 기능 커밋을 `git revert`한 뒤 정상 배포 절차로 되돌린다. 다른 사용자 변경을 지우는 reset/강제 push는 사용하지 않는다.
3. 기능 커밋 전 상태를 가리키는 로컬 `rollback/shotgun-pre-spatial-20260920` 브랜치를 보존한다. 롤백 시에는 이 변경 후 만들어진 공유 코드의 신규 필드가 구버전에서 무시될 수 있음을 알린다.

## 스킬 간 상호작용
- 마이야르와 블렌칭은 상호 배타적 상태다. 공격 방식이 상태를 만들고 반대 상태를 제거하며, 버스트 분기와 풀버스트 진입 버프가 현재 상태를 읽는다.

## 유저 확인 사항
- 블라블라링크와 원시 데이터가 일치한다.
- 기본 오토 시뮬은 풀차지 도달 즉시 발사하므로 `1초 이상 유지`를 충족하지 않는다. 블렌칭은 명시 홀드, 마이야르는 비풀차지 톡톡이 컨트롤에서만 검증한다.
- `마이야르나 블렌칭 상태인 대상`은 두 named buff 중 하나가 있는 아군 합집합으로 해석한다.

## 해석 선언

| 효과 | 해석 | 상태 |
|---|---|---|
| 블렌칭 카운터 | 풀차지 도달 후 1초 이상 유지한 행동을 3회 누적할 때마다 발동한다. 기본 오토 풀차지는 해당하지 않는다 | 확인 완료(타임라인 테스트)·게임 실측 필요 |
| 마이야르 카운터 | 풀차지 전에 발사한 일반 공격을 3회 누적할 때마다 발동한다 | 가정 적용·추가 실측 필요 |
| 모드 전환 | 새 상태 부여 뒤 반대 named buff를 제거해 두 상태를 상호 배타적으로 유지한다 | 확인 완료(파싱 순서) |
| 상태 대상 합집합 | 마이야르와 블렌칭 대상 배열을 합집합으로 풀며 중복 대상은 한 번만 적용해야 한다 | 추가 자동 테스트 필요 |
